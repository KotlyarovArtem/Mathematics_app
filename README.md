# 🌈 Математика — это весело!

Локальное desktop-приложение для детей **6–10 лет** (1–4 классы) для проверки
и развития навыков устного счёта. Написано на **Python + PySide6**, не требует
ни одного внешнего медиафайла — вся графика рисуется кодом через `QPainter`.

---

## ✨ Возможности

- 🎨 **Детский Flat Design** на QSS в пастельных тонах (мятный, голубой, жёлтый, коралловый); при маленьком окне содержимое прокручивается, а не искажается.
- 🧚 **Два персонажа-помощника — настоящие 3D-модели** (GLB, glTF 2.0): **Фея Динь** (`Images/Fairy/fairy_one.glb`) и **Боевой Прайм** (`Images/Prime/War_Prime.glb`). Рендер на GPU через ModernGL: PBR-шейдер (Cook-Torrance GGX) с normal-маппингом, три источника света с контровым, мягкая тень; персонажи медленно вращаются на «витрине» и парят. При отсутствии файлов моделей или OpenGL — автоматический откат на 2D-версии, нарисованные кодом.
- 🚀 **Полётные анимации перед заданием**: персонаж подлетает к месту РЯДОМ с карточкой — Фея Динь на крыльях, осыпая путь пылью, затем бросает горсть волшебной пыли по крутой дуге; Боевой Прайм на реактивном ранце стреляет снарядом из пушки на руке по настильной траектории. На месте падения вырастает оседающее облако (шейдерные частицы), одновременно персонаж возвращается назад и стартует генерация.
- ➡️ **Поле ответа в строке примера**: «A + B = [поле]» на одном уровне, до 10 символов.
- 👤 **Регистрация ученика**: имя вводится или выбирается из **выпадающего списка**, который формируется из сохранённых JSON-файлов статистики.
- 🎓 **Выбор класса с учётом возраста**: 6–7 лет → 1 класс; 8 лет → 1–2; 9 лет → 1–3; 10+ лет → 1–4.
- 🎰 **Генерация примера — экран автомата «однорукий бандит»**: каждая цифра -- барабан с вертикальной лентой цифр и затемнением свода; барабаны фиксируются слева направо с интервалом 200 мс.
- ➗ **Генератор примеров** по классам с правилами форм действий (см. таблицу ниже).
- ✅ **Мгновенная проверка** с яркой анимацией и репликой персонажа в облачке: «Верно! Ты молодец! Классно!» с лучами и объёмным GPU-конфетти (глубина, вращение, трепетание) или мягкое «Не правильно. В следующий раз обязательно получится» со всплывающими пузырьками.
- 🔄 **Задания не повторяются** в течение трёх ближайших сессий (и внутри текущей).
- 📊 **Полноценное окно статистики** (отдельное, перетаскиваемое, разворачиваемое): все метрики, таблица всех сессий и график прогресса на QtCharts.
- 🏆 **Пятибалльная оценка** за сессию и средняя оценка за класс с анимированным бейджем.
- 🛡️ **Защита от некорректного ввода**: поле ответа принимает только целые числа.
- 💾 **Статистика сохраняется рядом с программой** (папка `data`), в том числе в собранном `.exe` — прогресс и имена учеников не теряются между запусками.

## 🚀 Запуск

### Шаг 1. Установить Python 3.10+

Скачайте с [python.org](https://www.python.org/downloads/). На Ubuntu:
```bash
sudo apt update && sudo apt install python3 python3-venv python3-pip
```

### Шаг 2. Создать виртуальное окружение и установить зависимости

**Linux / macOS:**
```bash
cd MathApp
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell):**
```powershell
cd MathApp
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Шаг 3. Запустить приложение

```bash
python main.py
```

Появится окно приложения. Введите имя, возраст, выберите класс и помощника,
нажмите **«🚀 Начать проверку»**.

## 🧪 Запуск тестов

Тесты проверяют генератор примеров (все классы, включая формы умножения и
деления), отсутствие деления на ноль и остатка, диапазоны чисел, защиту от
повторов в трёх ближайших сессиях, подсчёт оценок и работу менеджера
статистики:

```bash
pip install pytest
python -m pytest test_math_app.py -v
```

Ожидаемый результат: **76 тестов пройдены** (+GPU-тесты шейдеров и
3D-моделей, если доступен OpenGL и файлы моделей на месте).

## 📦 Сборка в .exe (Windows)

**Быстрый запуск важнее одного файла** — используйте `--onedir`: `--onefile`
при каждом старте распаковывает ~200 МБ во временную папку (это задержка в
несколько секунд). Рекомендуемая команда:

```bash
pip install pyinstaller
pyinstaller --noconsole --onedir --name "Математика" ^
  --add-data "Images;Images" ^
  --collect-all PySide6 ^
  --exclude-module PySide6.QtWebEngineCore ^
  --exclude-module PySide6.QtWebEngineWidgets ^
  --exclude-module PySide6.QtWebChannel ^
  --exclude-module PySide6.QtQml ^
  --exclude-module PySide6.QtQuick ^
  --exclude-module PySide6.QtQuickWidgets ^
  --exclude-module PySide6.QtNetwork ^
  --exclude-module PySide6.QtSql ^
  --exclude-module PySide6.QtTest ^
  --exclude-module PySide6.QtPdf ^
  --exclude-module PySide6.QtDesigner ^
  --exclude-module PySide6.QtUiTools ^
  --exclude-module PySide6.QtBluetooth ^
  --exclude-module PySide6.QtNfc ^
  --exclude-module PySide6.QtPositioning ^
  --exclude-module PySide6.QtSensors ^
  --exclude-module PySide6.QtSerialPort ^
  --exclude-module PySide6.QtWebSockets ^
  --exclude-module PySide6.QtMultimedia ^
  --exclude-module PySide6.QtMultimediaWidgets ^
  --exclude-module tkinter ^
  main.py
```

**Как ускорен запуск** (уже сделано в коде): тяжёлые модули `numpy` и
`moderngl` импортируются лениво (только при реальном GPU-рендере), график
QtCharts -- при открытии статистики; GL-контекст и 3D-модели грузятся после
показа окна (окно появляется мгновенно, персонажи -- через долю секунды).
Дополнительные советы: не запускайте exe с сетевого диска, при первом
запуске Windows SmartScreen может проверить файл; в папку сборки можно
добавить пустой файл `qt.conf` не нужно -- PyInstaller всё делает сам.

Пояснение:
- `--noconsole` — окно без чёрной консоли (GUI-приложение);
- `--add-data "Images;Images"` — упаковывает GLB-модели персонажей
  (в Linux/macOS замените `;` на `:`);
- `--onedir` — папка с exe и библиотеками: старт почти мгновенный, без
  распаковки во временный каталог при каждом запуске;
- `--exclude-module ...` — выкидывает неиспользуемые модули Qt (WebEngine,
  QML, Network и т.п.): минус ~150 МБ и заметно быстрее загрузка;
- `--collect-all PySide6` оставляет только нужные плагины платформ.

Дополнительные оптимизации запуска уже встроены в код: QtCharts (тяжёлый
модуль графиков) импортируется лениво — только при открытии окна статистики;
GPU-персонажи ставят анимацию на паузу, когда не видны.

Готовая папка появится в `dist/Математика/` (для ярлыка берите
`Математика.exe` внутри неё). Вариант с `--onefile` тоже работает, но
стартует медленнее.

**Где хранится статистика.** Приложение определяет папку с `.exe` (даже в
режиме `--onefile`, когда Python-файлы распаковываются во временную папку) и
создаёт каталог `data/` **рядом с исполняемым файлом**. Именно оттуда
формируется выпадающий список имён учеников, поэтому прогресс, имена и оценки
сохраняются между запусками собранного приложения. Не помещайте `.exe` в
папки, защищённые от записи (например, `C:\Program Files`), — иначе Windows
не позволит создать `data/`; лучше `C:\MathApp\` или Рабочий стол.

## 🛠️ Troubleshooting

### 1. `qt.qpa.plugin: Could not load the Qt platform plugin "xcb"`
**Причина:** в Linux не хватает системных библиотек для отрисовки окон.
**Решение (Ubuntu/Debian):**
```bash
sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libxcb-xinerama0 \
  libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 \
  libxcb-shape0 libegl1 libgl1
```
Если ошибка остаётся, попробуйте `sudo apt install qt6-base-dev`.

### 2. График статистики пустой / `ModuleNotFoundError: No module named 'PySide6.QtCharts'`
**Причина:** в минимальной установке PySide6 модуль QtCharts может отсутствовать.
**Решение:** переустановите PySide6 полностью:
```bash
pip install --force-reinstall PySide6
```
При сборке через PyInstaller обязательно добавляйте `--collect-all PySide6`.

### 3. Ошибка `externally-managed-environment` при `pip install` (Ubuntu 23.04+)
**Причина:** системный Python защищён от прямой установки пакетов (PEP 668).
**Решение:** всегда используйте виртуальное окружение (см. раздел «Запуск»),
либо установите через `pipx`:
```bash
pipx install PySide6
```

### 4. Персонажи вместо 3D-моделей показываются плоскими (Linux)
**Причина:** приложение автоматически проверяет OpenGL при запуске; при
недоступности GL 3.3+ оно честно печатает в консоль
`[MathApp] OpenGL недоступен (причина) -- персонажи отрисованы в 2D` и
работает на 2D-персонажах. На Wayland-сессиях с некоторыми драйверами
прямой GL недоступен — приложение само переключается на XWayland; если
проблема остаётся, запустите с явной платформой:
```bash
QT_QPA_PLATFORM=xcb python main.py
```

### 5. Кракозябры / иероглифы вместо русских букв (Windows)
**Причина:** консоль в кодировке cp866/cp1251, а не UTF-8.
**Решение:** запустите файл через `python main.py`, а не двойным кликом по
`.bat`, либо смените кодировку консоли:
```cmd
chcp 65001
python main.py
```
В самом приложении (в окне) кириллица отображается корректно в любой системе.

## 🎯 Логика оценок

| Правильных ответов | Оценка |
|---|---|
| 95–100 % | **5** |
| 80–95 % | **4** |
| 60–80 % | **3** |
| 40–60 % | **2** |
| менее 40 % | **1** |

**Оценка за класс** = среднее арифметическое всех оценок за сессии в этом классе.

## 📐 Правила генерации примеров

| Класс | Действия | Диапазоны (+, −) | Формы умножения | Формы деления | Сложные примеры |
|---|---|---|---|---|---|
| **1** | +, − | 0…20 (все промежуточные и итог) | — | — | ~1 из 5: «(A + B) − C», все результаты 0…20 |
| **2** | +, −, ×, ÷ | 0…100 | однозначное × однозначное (таблица) | однозначное или двузначное ÷ однозначное (табличное, делимое ≤ 81) | ≤20 %, однозначные в скобках |
| **3** | +, −, ×, ÷ | 0…1000 | один множитель однозначный, второй двузначный, произведение ≤ 100 | делитель однозначный, делимое — до трёхзначного (≤ 999), частное двузначное | ≤20 %, однозначные и двузначные |
| **4** | +, −, ×, ÷ | 0…1 000 000 | числа и результаты 1…1 000 000 | числа и результаты 1…1 000 000 | ≤20 %, от двузначных до пятизначных |

Гарантируется: только целые ≥ 0, деление без остатка, нет деления на ноль,
нет отрицательных промежуточных результатов в скобках, пример старшего класса
не совпадает с примером младшего (включая сложные примеры со скобками),
пример не повторяется в течение трёх ближайших сессий.

## 🧱 Технологии

- **Python 3.12+** (тестировалось на 3.12 и 3.14)
- **PySide6 6.6+** (Qt for Python) — все окна, QtCore, QtGui, QtWidgets, QtCharts
- **ModernGL** (OpenGL 3.3 Core) — 3D-модели персонажей GLB (свой
  glTF-парсер + PBR-рендер) и шейдерные эффекты: пул из 4096 частиц
  (позиция/затухание/оседание считаются в vertex-шейдере)
- **numpy** — матричная математика камеры/моделей
- **Отказоустойчивость**: при недоступности OpenGL всё приложение
  автоматически работает на QPainter — без сбоев на старых машинах
- Никаких внешних ассетов: графика рисуется кодом

> **Почему не Arcade?** Arcade — самостоятельный игровой фреймворк со своим
> окном и циклом событий (pyglet) и не может быть встроен в окна PySide6.
> Все требования «объёмной» GPU-графики (шейдерные персонажи и частицы)
> закрывает ModernGL, встроенный напрямую в Qt-виджеты (QOpenGLWidget).
